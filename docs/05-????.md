## 3. 分模块验收详表

### A. 可运行产物（D-01）

| 项 | 要求 |
|---|---|
| 形态 | `.apk`；优先 arm64-v8a；release 需签名（签名归属见文档 00 Q3） |
| 验收 | ①真机可安装 ②冷启动见 A1 ③模式 A 核心 7 流程通过 ④模式 B 至少 HTTP 单任务（P0 口径）**[真机]** |
| 前提 | D-02/03/04/05/06 就绪 |

### B. 安卓工程源码（D-02）

- 必备：`MainActivity`（WebView）、JS 桥 `MotrixAndroid`（getServerBase/pickDownloadDir/notify/storageInfo/keepAwake）、前台服务、AndroidManifest（权限/Intent Filter）、资源 `res/`。
- 验收：`gradlew assembleDebug` 成功；Manifest 权限仅 INTERNET/FOREGROUND_SERVICE(+DATA_SYNC)/POST_NOTIFICATIONS（A3）；WebView 加固项（A10）。**[构建]**

### C. renderer 资源（D-03）

- 来源：`pnpm build:server` 产出 `dist/renderer-web`（base `./`），构建脚本 stage 进 assets。
- 验收：WebView 加载无白屏/无 404；桌面原版功能不因移动端适配被破坏。**[真机]**

### D. 端内 Node 启动脚本（D-04）

- 关键点：设 `MOTRIX` 监听端口、下载目录、`MOTRIX_SKIP_ELECTRON_REBUILD=1`、`MOTRIX_ARIA2_PATH`；`import('.../dist/server/index.mjs')`。
- 验收：起服务 + 健康检查 + 拉起 aria2c 成功。**[构建]+[真机]**

### E. 构建脚本组（D-05）

| 脚本 | 作用 | 验收 |
|---|---|---|
| `install-toolchain.ps1` | 装 JDK17 + Android SDK + NDK | 幂等、失败提示清晰 |
| `fetch-aria2-android.ps1` | 取安卓 aria2c（arm64/armv7） | 校验 hash、放对位置、带 LICENSE |
| `build-renderer.ps1` | pnpm 构建 dist/renderer-web + dist/server | 产物齐全、stage 到 assets |
| `build-all.ps1` | 一键 renderer→stage→gradle assemble | 一条命令出 APK **[构建]** |

### F. aria2 二进制（D-06）

- 路径：`jniLibs/<abi>/libaria2c.so`（可执行）
- 验收：ABI 匹配真机可执行；来源与 LICENSE 齐全；启动赋 0755。**[真机]**

### G. 移动端适配层（D-07）

- 4 文件：`mobile-adapt.css` / `mobile-adapt.js` / `README.md` / `screens.md`
- 验收：低侵入、通用、可开关、不臆造 class 名、README 注明"需按实际 DOM 微调"；竖屏 360dp 无溢出。**[真机]**

## 4. 面向零基础用户：装/用/验 指路（详见 D-12）

> 本清单只做"指路"，完整步骤以 `README.md` / `docs/03-构建指南.md` 为准。

1. **装**：把 D-01 的 APK 拷到手机 → 允许"未知来源" → 安装 → 首次打开按提示授予通知权限、选下载目录（SAF）。
2. **用**：选择运行模式（模式 B 端内；或模式 A 填服务器 URL + bridge 配对）→ 新建任务（粘贴直链/磁力，或选 .torrent）→ 在任务列表查看进度、暂停/继续/删除。
3. **验**：对照文档 00 §8 抽查——能否下一个 HTTP 文件、限速是否生效、切后台锁屏是否继续、文件在选定目录能否看到。
