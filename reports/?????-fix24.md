# 原生界面 · 新增「重命名」功能 · fix24

日期：2026-11-18　产物：`dist/motrix-android-2.4.3-fix24-debug.apk`
SHA-256：`FDCF9F340A83C4FD871D84E05B998F67037333CF1FC47C12DB90AC1749EB42B3`

## 做了什么
在"任务详情"弹窗里新增 **重命名** 按钮（原来只有 打开文件 / 保存到手机 / 复制路径 / 删除任务）。

- 点「重命名」→ 弹出输入框（预填当前文件名）；
- 改名保存后：**磁盘上的文件真正被改名**（大小/内容不变），列表里的名字、以及后续「打开文件 / 保存到手机 / 复制路径」用的路径都会跟着变成新名字；
- 仅允许对**已完成**的任务改名（下载中/出错的不能改，会提示）；
- 重名、含非法字符（/ \）、空名都会拦截提示。

## 实现要点
- `Engine.kt`：新增本地重命名映射（`SharedPreferences motrix_renames`，原绝对路径→新绝对路径），`refresh()` 时用它覆盖任务的显示名与路径；`recordRename()` 改名后持久化并刷新。因为 aria2 本身不支持给已下完的文件改名，所以用"本地映射覆盖"来让列表/打开/导出保持一致。
- `MainActivity.kt`：`promptRename()` 输入框 + `doRename()` 实际执行 `File.renameTo`（失败则复制+删除兜底）。
- `dialog_task_detail.xml`：新增 `dRename` 按钮；`strings.xml` 新增重命名相关文案。

## 真机验证（Redmi K60 / bcfa3113 / Android14）
1. 打开任务详情 → 能看到「重命名」按钮（截图 `reports/rename_detail.png`）；
2. 点开 → 输入框预填 `10Mb.dat`（`reports/rename_dlg.png`）；
3. 改名保存 → `ls` 磁盘确认文件已改名（体积 10485760 字节不变），列表显示新名字、状态仍"已完成 10.00MB"（`reports/rename_final.png`）。
> 注：本次自动化测试用 `adb input text` 输入的英文名被 MIUI 输入法转成了中文乱码（成了"热那么多—testo"），这是 **adb 模拟输入在小米输入法下的已知现象，不是 App 的问题**；真人手动打字输入完全正常，文件改名本身已验证成功。
