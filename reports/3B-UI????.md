## 0. 使用约定

### 0.1 字段定义

| 字段 | 说明 |
|---|---|
| 编号 | UI 走查缺陷用 `UI-###`（三位顺延，不复用）；3B 需求转译缺陷用 `D-3B-##`（对齐 `docs/11`）。同一现象两种编号共用一个档案，以 `D-3B-##` 为权威、`UI-###` 作历史登记 |
| 页面 | 见 0.3 页面清单，取其一（设置弹窗需注明具体弹窗名） |
| 现象 | 一句话客观描述「在哪、看到什么、与预期差多少」，不带主观评价 |
| 严重度 | P0/P1/P2，定义见 0.2 |
| 复现步骤 | 可复现的最短路径，含断点/页面/操作（如 `<640 → 下载页 → 折叠侧栏 → 看筛选栏`） |
| 期望 | 修复后应达到的正确表现（可验收口径） |
| 判定口径 | 该条**打勾/判 PASS 的具体通过标准**（用于验收矩阵逐格比对） |
| 状态 | `待修` / `修复中` / `已修(<版本号>)` / `待复现` / `⏸挂起` / `不修(说明)` |
| 证据截图路径 | 相对 `reports/` 的截图文件名，如 `reports/fix16_*.png`；未采集写「待补」 |

### 0.2 严重度定义

| 级别 | 定义 | 典型 |
|---|---|---|
| **P0** | 内容不可见/不可操作、导航死锁、配置丢失、全页面级遮挡 | 状态栏遮挡全页内容、仪表板底部被裁、筛选栏被顶栏遮挡 |
| **P1** | 单页面显著错位/遮挡/重叠，影响该页正常使用、但有规避路径 | 窄屏标题与徽标重叠、侧栏召回难、缺返回原生入口 |
| **P2** | 轻度视觉瑕疵、边缘场景、不阻断主流程 | 悬浮控件轻微挡内容、间距不齐 |

### 0.3 页面清单（覆盖范围）

`仪表板` · `下载` · `Trackers` · `通知` · `设置(各弹窗：基础/下载目录/限速/BT/Tracker/高级/关于)` · `新建(任务弹窗)` · `详情(任务详情面板)`

### 0.4 断点与侧栏口径（对齐 docs/10、docs/11，禁用自造 600/720）

- **三档断点**：`≥768`（平板/大屏）｜`640–767`（手机大屏 / 小平板竖屏）｜`<640`（手机窄屏，如红米 K60）。
- **侧栏两态**：`展开` / `隐藏`（隐藏即进入 compact-header 紧凑态；`<640` 时走纵向下移兜底）。
- **M·O 顶栏**：40px 高、`fixed; z-index:30` 透明应用外壳条——内容必须自行让出，否则重叠。

### 0.5 状态流转

`待复现` →（确认存在）`待修` → `修复中` → `已修(<fix版本号>)`；无需修复转 `不修(说明)`；未标注转 `⏸挂起`。每条 `已修` 须在第 2 节对应断点/侧栏格子做回归勾选（`✅`）。
