## 二、架构（为什么这条路最稳）

Motrix v2.4.3 是"React Web 前端 ↔ HTTP/WS ↔ Fastify server + core 引擎"的前后端分离结构。要在手机上"单机、可分发"，三种路线权衡后选**路线1**：

- 不跑 Node（避开 Fastify5/vite8 需 Node20+、以及 nodejs-mobile 主流 Node18 的最大不确定）；
- 端内直接跑官方 aria2 引擎二进制 + Kotlin 原生外壳，把"下载内核"忠实搬过来；
- 风险最低、可先出单机可用版；日后可平滑升级到路线3（保留 Motrix 原生 Web 界面）。

分层：
```
Android 原生 UI (RecyclerView 任务列表 / 设置 / 前台服务)
      │  StateFlow
Engine (Kotlin 单例：进程 + JSON-RPC 客户端 + 轮询合并)
      │  HTTP JSON-RPC 127.0.0.1:<port>/jsonrpc  (token)
aria2c 子进程（jniLibs 内置 arm64/armv7 静态二进制）
      │
下载落盘 → 应用专属外部目录 /Downloads
```

## 三、功能清单（已实现）

- 下载协议：HTTP/HTTPS、FTP、磁力（magnet:）、BT 种子（.torrent）
- 任务列表：名称、进度条、已完成/总大小、下载/上传速度、连接数
- 任务操作：暂停 / 继续 / 删除（forcePause/unpause/forceRemove + removeDownloadResult）
- 全局操作：全部暂停 / 全部开始 / 清除已完成（pauseAll/unpauseAll/purgeDownloadResult）
- 设置：下载目录、最大同时下载数、下载限速(KB/s)、上传限速(KB/s)、做种时长、RPC 端口/密钥
- 前台服务 + 常驻通知：后台可持续下载（dataSync 前台服务）
- 磁力链接接管：点其他应用里的 magnet: 链接可直接唤起添加
- RPC 安全性：aria2 仅监听 127.0.0.1（`--rpc-listen-all=false`）+ token 密钥

## 四、内置 aria2 二进制（关键技术点）

- 来源：`abcfy2/aria2-static-build` release 1.37.0（musl 静态）
- 放置为 `jniLibs/arm64-v8a/libaria2c.so`（14,455,008B）与 `armeabi-v7a/libaria2c.so`（12,304,196B）
- 以 `libaria2c.so` 之名打进 APK → 被解压到**只读可执行的 nativeLibraryDir** → 直接 execve 执行
  （绕开 Android 10+ 对 App 可写目录执行二进制 W^X 限制）
- 证书：内置 `assets/cacert.pem`（200,116B），aria2 走 `--ca-certificate` 支持 HTTPS
