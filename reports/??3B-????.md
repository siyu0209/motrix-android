# 路线 3B 交付报告（原版 Motrix 界面 + 端内 aria2 本地兼容桥）

生成时间：2026-11-18
工程：`C:\工作日志\projects\motrix-android\android`
产物：`dist\motrix-android-2.4.3-classic-3b-debug.apk`

## 一、这一版做了什么

在原「路线1 原生简洁版」基础上，新增**路线3B**：把 agalwood/Motrix v2.4.3 的**原版 React 前端**（`dist/renderer-web`，73 个文件 / 8.89MB，含原生 `app-root`、`add-task`、`settings`、多语言、图表、目录选择器等）打进 APK，
并用一个**本地兼容 server**（`BridgeServer`，NanoHTTPD/NanoWSD）在同源 `http://127.0.0.1:18601/` 上：

1. 静态托管 `assets/renderer-web/*`（SPA，缺失路径回退 index.html）；
2. 提供 `/rpc/auth/status`（本地单用户直接 `authed:true`，renderer 不会停在解锁屏）+ `/rpc/auth/login`；
3. 把 `POST /rpc/{query|command}/<channel>` 交给 `RpcDispatcher`，翻译成端内 **aria2 JSON-RPC**；
4. 提供 `/rpc/events` **WebSocket**：心跳 + 周期推送 `event:statsUpdated` / `event:taskUpdated`。

这样原版前端以「同源」方式加载，`transport` 自动把后端指向本机，无需改渲染器（依据 `src/renderer/lib/web-base-url.ts` 的同源铁律）。

## 二、契约对齐（静态验证，已通过）

打包后的前端 JS 中确认存在与本桥完全一致的通道串：
`query:listTasks` / `query:getStats` / `query:getSettings` / `command:createTask` / `event:statsUpdated` / `event:taskUpdated` / `/rpc/` / `rpc/events`。
`RpcDispatcher.kt`（931 行）对 aria2 状态的映射严格对齐 `src/core/engine/aria2/translate.ts`（九态 status、progress/eta/name/去 `.motrix`、bt 扩展、errorCode→`DL_*`），Aria2Rpc 真实签名逐条匹配。

## 三、如何打开原版界面

APK 启动进入「原生简洁版」主界面；右上角菜单 → **「打开原版界面（3B）」** 即进入原版 Motrix UI（`MotrixWebActivity`）。
一个安装包内在两套界面：
- 原生简洁版（路线1，稳定、轻）；
- 原版完整界面（路线3B，还原原版布局/交互）。

## 四、诚实的功能边界（需真机验证 / 已知缺口）

- **运行时尚未真机验证**：本机无真机/模拟器（adb 空、无 system-image）。「编译通过 + 前端原版界面与桥已正确打包 + 协议串对齐」已验证；「UI 是否零报错启动、真实 HTTP/BT 下载、后台保活、权限弹窗」需插手机实测。
- **parseTorrent 缺口**：端侧无 bencode 解析器，渲染器「选择 .torrent 文件」的文件列表会为空 —— 磁力链、直链正常；.torrent 文件路径建议先用磁力替代。后续可加极简 bencode 解析补齐。
- **settings 多为占位默认**：`getSettings` 返回结构完整但非真实用户值；渲染器对部分设置较宽容（源码测试中 mock 成 `{app:{}}` 仍可运行），枚举/取值极端情况可能需按 zod 报错微调。
- **未实现的桌面专属通道**（自动更新/托盘/AppImage/CLI/NAT 诊断等）返回 null / `{ok:true}` 降级，保证不崩。
